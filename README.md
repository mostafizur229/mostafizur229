### 🎯 **Executive Summary**

I am a **Full-Stack & Enterprise Solutions Engineer** with strong production experience in architecting scalable distributed systems, Enterprise Resource Planning (ERP), Inventory Management Systems (IMS), and cross-platform mobile solutions using the latest tech stacks.

Currently developing enterprise systems at **Object Canvas Technology**. I specialize in building mission-critical backend systems with strict Clean Architecture and coupling them with blazing-fast Next.js and Flutter frontends.

- ⚡ **Backend & Core:** .NET 9, C# 13, ASP.NET Core Web API, Clean Architecture, CQRS, MediatR, EF Core 9.
- 🎨 **Modern Frontend:** Next.js 15 (App Router & Turbopack), React 19, TypeScript 5.7, Tailwind CSS.
- 📱 **Mobile Ecosystem:** Flutter 3.24+ & Dart (Cross-platform for Android & iOS).
- 🗄️ **Data & Infrastructure:** Microsoft SQL Server 2022, PostgreSQL, Redis Caching, Docker, IIS.

#### 1. 🛍️ [NexCommerce Enterprise (Full-Stack Platform)](https://github.com/mostafizur229/EcommerceWithNextJs)
> High-performance digital commerce platform built on Next.js 15 & ASP.NET Core 9 Clean Architecture.
* **Architecture:** Decoupled Monorepo (`Next.js 15 App Router` + `ASP.NET Core 9 Web API` + `SQL Server 2022`).
* **Highlights:** Real-time AI Product Compare Modal, recursive category tree navigation, multi-warehouse stock allocation, and JWT-authenticated checkout flow.
* **Stack:** `.NET 9`, `Next.js 15`, `React 19`, `TypeScript 5.7`, `Tailwind CSS`, `EF Core 9`

#### 2. 🏍️ [MotoCore DMS (Dealership & Distribution ERP)](https://github.com/mostafizur229/eBikeDealerShipManagement)
> Mission-critical Dealership Management System (DMS) for automotive & e-bike distribution networks.
* **Architecture:** Uncle Bob’s Clean Architecture (`Domain`, `Application`, `Infrastructure`, `API`).
* **Highlights:** Chassis/Frame serial tracking, installment calculation engine, dealer commission tiers, multi-godown stock transfers, and automated after-sales servicing logs.
* **Stack:** `ASP.NET Core 9`, `Clean Architecture`, `EF Core 9`, `MS SQL Server 2022`, `Swagger`

#### 3. 📱 [BPower Pulse Mobile Suite](https://github.com/mostafizur229/B-PowerMobileApps)

* **Highlights:** Offline-first caching, live battery & telemetry status, responsive UX across Android & iOS, and push notification sync.
* **Stack:** `Flutter 3.24+`, `Dart`, `RESTful APIs`, `Reactive State Management`

#### 4. ⚙️ [BPower Core API Gateway](https://github.com/mostafizur229/B-powerBakend)
